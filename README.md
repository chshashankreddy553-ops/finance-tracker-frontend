# Personal Finance Tracker - Frontend

A responsive web application frontend for tracking personal income, expenses, and net balance with JWT authentication.

## 🚀 Features
- **User Authentication**: Login and Registration interfaces with JWT token management.
- **Financial Dashboard**: Summary cards for Total Income, Total Expenses, and Net Balance in Indian Rupees (₹).
- **Transaction Management**: Add and delete transactions with category tags and date tracking.
- **REST API Integration**: Communicates seamlessly with the Spring Boot backend API.

## 💻 Tech Stack
- HTML5
- CSS3 (Responsive Grid & Flexbox)
- JavaScript (Fetch API, LocalStorage, Async/Await)
